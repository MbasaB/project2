# Personal Profile Card

A simple personal profile webpage created to practise front-end development with HTML and CSS.

## Overview

This project displays a personal profile card with a photograph, a short introduction, and contact links. It is an early learning project that demonstrates basic webpage structure, styling, and hover effects.

## Built with

- HTML5
- CSS3

## Features

- Profile photo and introductory text
- Email and LinkedIn contact links
- Styled card with a hover effect
- Basic responsive CSS

## Run locally

1. Clone or download this repository.
2. Keep `index.html`, `style.css`, and `mbasa.jpg` together in one directory.
3. Open `index.html` in a web browser.

No build tools or server are required.

## Project status

An early front-end practice project. The profile content reflects the period when it was created and may not describe my current studies or experience.
